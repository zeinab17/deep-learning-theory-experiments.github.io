# deep-learning-theory-experiments.github.io
Research-oriented experiments and theoretical notes on hierarchical and representation learning in deep neural networks, with emphasis on optimization dynamics, mathematical structure, and reproducible Python implementations.
## Research Questions
- How does network depth contribute to hierarchical feature formation?
- What optimization dynamics emerge in over-parameterized deep models?
- How do linear and nonlinear representations differ across layers?
- When do synthetic hierarchies emerge without explicit supervision?
## Status
This repository is under active development and serves as a living research notebook.
Experiments are designed to be minimal, interpretable, and reproducible.

## Overview
This repository contains research-driven experiments and notes exploring hierarchical learning in deep neural networks. 
The goal is to understand how depth, compositional structure, and optimization interact to shape learned representations.

## Motivation
Hierarchical representations are central to modern deep learning systems, yet their theoretical and empirical behavior remains only partially understood.
This repository serves as a personal research notebook bridging theory and practice.

## Topics Covered
- Hierarchical feature learning in deep models
- Optimization dynamics in over-parameterized networks
- Linear and nonlinear representation analysis
- Synthetic experiments for controlled theoretical insight
